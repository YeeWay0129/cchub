# cchub：用手機遠端開專案

這台電腦用 `cchub` 替專案資料夾起官方的 `claude remote-control` 伺服器。伺服器起來後，
手機 Claude App → Code → 這台電腦的卡片上會多一筆，點它就能在那個專案開新 session。

## 規則

1. **一律用 `cchub`（指令名稱）開頭呼叫**，不要用絕對路徑、`bash -c`、`env …`、`python3 …/cchub`
   等寫法——使用者層級的確認規則只比對 `cchub …` 開頭的寫法，繞過它等於跳過使用者的確認。
2. 用繁體中文回覆。
3. 執行 `cchub new` 之前，先用一句話告訴使用者它會做什麼：
   在 `@@PROJECTS_ROOT@@/<名稱>` 建資料夾（CLAUDE.md 寫入需求）、git init、只替這個新資料夾寫信任、起伺服器。
   手機會跳一次確認，請使用者按允許。
4. **使用者的原話（需求）一律用 heredoc 從 stdin 傳入（`--brief-stdin`）**，照下面三條做：
   - 分隔字**每次都換一個新的**：`CCHUB_BRIEF_` 後面接 8 位隨機十六進位數字（例如 `CCHUB_BRIEF_3f9a01c7`），
     而且**一定要加單引號**：`<<'CCHUB_BRIEF_3f9a01c7'`。加了單引號，原文裡的 `$…`、反引號、引號、`\` 都原樣保留，不會被 shell 展開或執行。
   - 組指令前，**先確認需求原文裡沒有任何一行等於這個分隔字**；有的話換一個新的隨機字串再檢查一次。
   - **絕對不要**把使用者的原話直接寫在指令列上（不論用雙引號、單引號還是當成參數）。
   標題：組指令前，先把標題裡的單引號、雙引號、反斜線、換行**全部拿掉**，再用單引號包起來（`--title '…'`）。
   shell 會先解析整行指令，cchub 收到時已經來不及補救，所以這一步一定要你自己先做。
5. 成功時輸出第一行是「✅ … 選「X」開新 session」：照實轉述，告訴使用者回到卡片選哪一筆。
   輸出最後的「備用網址」是這台伺服器的環境網址（`https://claude.ai/code?environment=…`），可以一起附上。
6. 資料夾未受信任、或信任是繼承的但資料夾裡有 hooks／MCP 等設定時，cchub 會拒絕。
   請照它的說明告訴使用者：要回電腦在那個資料夾執行一次 `claude`，用官方對話框信任。
   **不要**嘗試其他方法繞過，也不要自己修改 `~/.claude.json`。
7. 不要執行 `cchub install`、`cchub uninstall`、`cchub _serve`、`cchub _reconcile`：那些只能在使用者自己的終端機跑。
8. 入口（`@@ENTRY_DIR@@`，卡片上的「@@ENTRY_LABEL@@」）不能停止；要重啟入口用 `cchub restart entry`。
   在手機的 session 裡（也就是在 cchub 管理的伺服器裡）執行時，重啟會延後 15 秒，讓你先把這一輪回覆完；
   在電腦上執行則會**立刻**重啟，正在進行的入口 session 會被中斷。

## 開新專案（照這個格式寫）

```bash
cchub new ledger --title '記帳工具' --brief-stdin <<'CCHUB_BRIEF_3f9a01c7'
<使用者的原話，照抄，不用跳脫任何字元>
CCHUB_BRIEF_3f9a01c7
```

- `3f9a01c7` 只是範例：**每次都換成新的 8 位隨機十六進位**，開頭那行與最後一行要一模一樣，而且原文裡不能有任何一行等於它。
- 名稱（`ledger` 的位置）只能是小寫英數與 `-`，最多 40 字；不合規則時先幫使用者換一個（例如「記帳工具」→ `ledger`），跟他確認後再執行。
- 標題（`記帳工具` 的位置）先拿掉單引號、雙引號、反斜線、換行。
- 最後一行的分隔字必須單獨成行、前後不能有空白。

## 其他指令

| 使用者說 | 執行 |
|---|---|
| 打開 X／讓手機進 X | `cchub open X`（資料夾名稱或絕對路徑） |
| 現在開著哪些？ | `cchub ls` |
| X 的狀態／紀錄 | `cchub logs X -n 30` |
| 關掉 X | `cchub stop X` |
| 重啟 X | `cchub restart X` |
| 檢查環境、哪些專案還沒受信任 | `cchub doctor` |

- 同名資料夾有兩個以上時，cchub 會列出完整路徑，請使用者選一個，再用絕對路徑執行。
- 專案伺服器最多 6 個（入口不算）；滿了會列出正在跑的，請使用者決定關哪個。
